## szukaj_cpu 1.0.5

### Fixed
* **A parked car no longer raises repeated events.** A vehicle that stays in the same place
  for `static_after` seconds (default 60) is remembered as stationary and further detections
  there are ignored. Arrival, departure and movement still raise events; people are never
  ignored. The list of stationary objects survives restarts (`~/.szukaj_cpu/nieruchome.json`).

### New options (`[detection]`, defaults used when missing)
```toml
static_classes = ["car", "truck", "bus", "motorcycle", "bicycle"]   # [] = off
static_after = 60        # seconds in the same place → stationary
static_forget = 21600    # forget a stationary object after 6 h unseen
```

## szukaj_cpu 1.9.1

### Recording directory
* Fixed the default recording directory when `[paths] recordings` already points to the
  Shinobi group directory (`…/videos/<group_key>`): the group key is no longer added a second
  time (`…/JbwBTUcD16/JbwBTUcD16/brama` → `…/JbwBTUcD16/brama`).
* Web panel → Cameras: the recording directory of each camera can be set by hand (empty =
  Shinobi layout, shown as a hint). Directories under `[paths] recordings` that already
  contain Shinobi recordings are listed – one click fills the field.
* Two cameras recording into the same directory are rejected with a clear message.

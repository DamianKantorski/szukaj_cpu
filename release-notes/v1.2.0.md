## szukaj_cpu 1.2.0

### INT8 model
* New `[detection] precision = "fp32" | "int8"`. INT8 is the YOLO11s model quantized with
  OpenVINO NNCF (post-training, calibrated on images): faster on the CPU, slightly less
  accurate. If the INT8 model for the configured size is missing, FP32 is used and a warning
  is logged.
* Web panel → Configuration → **Model**: version switch, list of available models (bundled
  and own, which one is running, which one the settings point to) with **Use**, upload of a
  model `.zip` (model update) and removal of own models. Save and restart to apply.
* Check on coco128 (128 images, FP32 math forced as on CPUs without bf16): INT8 kept
  184 of 188 detections (97.9 %, mean confidence change +0.001) and ran about 2.2× faster on
  the build machine (Xeon with VNNI). On the i5-7500 (no VNNI) the gain will be smaller –
  measure it with `tools/compare_models.py` on the server.
* `tools/export_models.py` – export FP32 and INT8 (`--calib` with frames from your cameras,
  `--zip` for the panel); `tools/compare_models.py` – speed and detection agreement of two
  models on a folder of images (run it on the server to see the real gain on your CPU).

### Self-contained package
* `packaging/build-deb.sh` builds the full package in a Debian 13 container (Docker/Podman):
  Python wheels for an offline install, FP32 and INT8 models, and ffmpeg/ffprobe compiled
  on the build machine (`-march=skylake`). The server no longer needs internet access to
  install. Cache in `build/`; `--slim` builds the program only, as before.
* The package is now `amd64` (bundled ffmpeg). `ffmpeg = "auto"` prefers your own
  `~/.szukaj_cpu/ffmpeg`, then the bundled one, then the system one.
* Release builds on GitHub Actions use the same script.

### Code structure
* `szukaj_cpu.py` (3000 lines) split into the package `src/szukaj_cpu/`: `config`, `camera`,
  `detector`, `export`, `events`, `gallery`, `clips`, `notify`, `main` and `web/` (server,
  configurator, TOML editing, model upload); the panel pages are separate `.html` files.
  Launcher: `/opt/szukaj_cpu/run.py` (systemd unit and `szukaj-cpu` updated).

### Upgrade
```bash
sudo apt install ./szukaj-cpu_1.2.0_amd64.deb
sudo systemctl restart szukaj_cpu@$USER
```
Your config keeps working (`precision` defaults to `fp32`). To try INT8: panel →
Configuration → Model → INT8 → Save and restart.

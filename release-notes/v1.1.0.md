## szukaj_cpu 1.1.0

### New: configuration page in the browser (`/admin/config`)
The settings panel now has two tabs: **Detection area** (as before) and **Configuration**,
which edits the rest of `szukaj_cpu.toml` without touching the file by hand.

* Side menu: Cameras, Detection, Parked vehicles, Clips, Gallery and web panel,
  Notifications, Shinobi, Paths and tools – with a badge counting unsaved changes.
* **Cameras:** add, rename, disable, remove; main and analysis stream addresses with a
  **Test** button (codec, resolution, fps, keyframe interval) and an **RTSP address wizard**
  for Dahua/Amcrest, Hikvision/Tiandy, Reolink and Uniview.
* Friendly controls: switches, sliders, unit hints (e.g. 21600 s = 6 h), class chips with
  the full COCO list.
* Secrets stay on the server: camera passwords appear as `********`, keys/tokens/passwords
  are write-only.
* **Save** lists every change before writing, validates the whole file like a service
  start, rewrites only changed keys (comments kept), keeps a `.bak` copy. **Save and
  restart** applies it immediately; a concurrent change to the file is detected.

### Other
* Detection-area page: shared navigation, `#cam=NAME` opens a given camera.

### Upgrade
```bash
sudo apt install ./szukaj-cpu_1.1.0_all.deb
sudo systemctl restart szukaj_cpu@$USER
```
The panel needs `http_port`, `http_user` and `http_password` in `[gallery]`.
